# Drop your platform screenshots here

Put each screenshot into the folder for its platform. **Any filenames are fine** —
I sort them by name, so if you want a specific order, prefix them `01-`, `02-`, …

```
incoming/
  ios/      → iPhone screenshots
  ipad/     → iPad screenshots
  watch/    → Apple Watch screenshots
  wear/     → Wear OS screenshots
  vision/   → Apple Vision Pro screenshots
  xr/       → Android XR screenshots
```

PNG, JPG or HEIC all work. Once these are committed to the branch, I crop each
one to the app screen, remove the simulator wallpaper/background, and inline the
result directly into the page (no external requests) — then delete this folder.
